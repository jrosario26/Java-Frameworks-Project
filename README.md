# Inventory Management Project

## Overview
A Java Spring Boot web application utilizing Thymeleaf for dynamic server-side rendering.

## Key Features
- Add, modify, and delete parts/products
- Data validation
- Navigation system
- Dynamic webpage rendering
- Database Integration

## Technologies Used
- Java
- Spring Boot
- Thymeleaf
- Bootstrap
- Maven
- Spring Data JPA
- Hibernate

## Architecture
- MVC (Model-View-Controller) architecture

## How to Run
Open a terminal and run this command:
java -jar target/demo-0.0.1-SNAPSHOT.jar
